🏛️ Arsitektur Modular Monolith

TaskFlow OS menggabungkan bot Discord interaktif dan Web Dashboard ke dalam satu runtime Node.js + TypeScript berkinerja tinggi.

💻

1. Presentation Layer

Dual-interface terpadu:

  • Discord Bot: Slash commands, modals, contextual menu, button components.
  • Web Dashboard: SPA Glassmorphism tanpa framework bloat, response time < 50ms.
🧠

2. AI & Business Logic Layer

Otomatisasi cerdas:

  • Google Gemini AI: Ekstraksi tugas NLP dari pengumuman dosen yang berantakan.
  • Checklist Parser: Otomatis membuat sub-tugas berjenjang dari instruksi.
  • Gamification Engine: Kalkulasi XP, level, dan streak harian mahasiswa.
⚙️

3. Distributed Delay Engine

Antrean pengingat presisi:

  • BullMQ + Redis: Pengingat berbasis distributed delayed jobs yang tahan restart.
  • 3-Stage Alerts: H-24 Jam (persiapan), H-3 Jam (countdown), H-30 Menit (final call).
🗄️

4. Data & Storage Layer

Penyimpanan persisten terstruktur:

  • PostgreSQL 16: Database relasional dengan skema terindeks optimal.
  • Prisma ORM: Type-safe queries, migrasi otomatis, dan data seeding.

⏰ Alur 3-Tahap Pengingat Bertingkat (Tiered Reminders)

Tahap 1 H-24 Jam

Notifikasi persiapan awal agar mahasiswa tidak menunda tugas.

➔
Tahap 2 H-3 Jam

Peringatan hitung mundur untuk memeriksa kelengkapan file.

➔
Tahap 3 H-30 Menit

Panggilan terakhir (Final Call) dengan tombol submit langsung.
